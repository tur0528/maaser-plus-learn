# איך מוסיפים מאמר או סיפור (בלי קוד)

את התוכן עורכים בדפדפן, ב־**Pages CMS**. זה עורך חינמי שמתחבר למאגר של האתר ב־GitHub. כל שמירה מעדכנת את האתר לבד, תוך דקה־שתיים.

> **פעם אחת בהתחלה** (אחרי שהאתר עולה ל־GitHub): נכנסים ל־https://app.pagescms.org ← **Sign in with GitHub** (עם החשבון tur0528) ← מאשרים את התקנת ה־GitHub App של Pages CMS על המאגר של האתר ← בוחרים את המאגר מהרשימה. מכאן והלאה זה רק "להיכנס ולכתוב".

## הוספת מאמר

1. נכנסים ל־https://app.pagescms.org ובוחרים את המאגר של האתר.
2. בתפריט שבצד לוחצים על **מאמרים**.
3. לוחצים על כפתור ההוספה (Add / +).
4. ממלאים את השדות:

   | שדה | מה כותבים |
   |---|---|
   | **כותרת** | כותרת המאמר, בעברית |
   | **כתובת העמוד** | שם קצר באנגלית, באותיות קטנות ועם מקפים, למשל `maaser-mibruto-o-neto`. זו הכתובת של העמוד באתר, ואחרי הפרסום לא משנים אותה |
   | **תקציר קצר** | 1–2 משפטים. התקציר מופיע בכרטיס ברשימת המאמרים ובתוצאות של גוגל |
   | **נושא** | הלכה / מס / מדריכים |
   | **תאריך פרסום** | התאריך של היום |
   | **תיבת "נבדק על ידי הרב"** | מסמנים **רק** אחרי שרב באמת עבר על המאמר |
   | **מקורות** | שורה לכל מקור. מקור עם קישור כותבים כך: `שם המקור: https://...` |
   | **תמונה** | לא חובה |
   | **טיוטה** | מסומן כברירת מחדל, ולכן המאמר **לא** מתפרסם. כשמוכנים לפרסם, מבטלים את הסימון |
   | **גוף המאמר המלא** | הטקסט המלא. בסרגל העריכה יש כותרות, הדגשה, רשימות, ציטוט וקישורים |

5. לוחצים **Save** (שמירה).
6. מחכים דקה־שתיים ומרעננים את האתר. המאמר יופיע ברשימה, ובדף הבית תחת "מאמרים אחרונים".

**טיפים:**
- כותרות בתוך המאמר בוחרים בסרגל כ־"Heading 2". את הכותרת הראשית האתר מוסיף לבד.
- ציטוט מפסוק או ממקור מסמנים כ־Quote, והוא יוצג בתיבה המעוצבת.
- כדי להוריד מאמר מהאתר בלי למחוק אותו, מסמנים שוב **טיוטה** ושומרים.

## הוספת סיפור (אחרי אישור)

סיפורים שגולשים שולחים בטופס **לא מתפרסמים לבד**:

1. הסיפור מופיע ב**תיבת הניהול** באפליקציית הקהילה ב־Base44 (אחרי שהיא תוקם, ראו `integrations/base44/README.md`).
2. קוראים אותו. אם הוא מאושר, ב־Pages CMS נכנסים ל־**סיפורים** ← כפתור ההוספה, ומעתיקים את הכותרת והטקסט. אם הכותב ביקש **עילום שם**, מסמנים את התיבה, והשם לא יוצג.
3. מבטלים את **טיוטה** ← **Save**.
4. בתיבת הניהול לוחצים "לאשר" על הסיפור, כדי שייצא מהרשימה.

## שינוי הניסוחים הכלליים

ב־Pages CMS ← **הגדרות האתר וניסוחים** אפשר לשנות:
- את הפסוק בדף הבית ("ובחנוני נא בזאת"), את כותרת אזור הנושאים, את המשפט בפוטר ואת השורה התחתונה.
- את שם הרב ותאריך הבדיקה. **משאירים ריק עד שיש רב אמיתי שהסכים להופיע בשמו.** כל עוד השדה ריק, התיבה "נבדק על ידי הרב" לא מוצגת.
- את כתובת האפליקציה, ודוא״ל ליצירת קשר אם יהיה (לא חובה. בלי דוא״ל, דפי הפרטיות והנגישות מפנים לטופס באתר).

## אישור הודעות בפורום

ב־Base44 ← האפליקציה של הקהילה ← עמוד **תיבת הניהול**:
- כל נושא, תגובה או סיפור חדש מחכים שם, עם מונה.
- "לאשר" מפרסם נושא או תגובה באתר. "לדחות" משאיר אותם מוסתרים.

לא נשלחים מיילים. אם בעתיד יהיה מייל ייעודי, אפשר להוסיף התראה במייל (`NOTIFY_EMAIL` ב־`integrations/base44/shared/community.ts`).
